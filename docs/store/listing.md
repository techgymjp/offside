## 日本語

**アプリ名**（30 文字以内）

```
オフサイドトラップ 〜ラインを上げて罠にかけろ〜
```

**簡単な説明**（80 文字以内）

```
パスの瞬間にDFを上げて、相手をオフサイドの罠にかけろ！遊びながらオフサイドのルールがわかるサッカーの3Dゲーム。
```

**詳しい説明**

```
ナイター照明に照らされた満員のスタジアム。相手のフォワードが、守備ラインの裏を狙って走り出す。
パスが出るその瞬間に、遅れているDFを上げてラインをそろえろ！相手をオフサイドの罠にかけて、ピンチを止めよう。
全10プレーで、何回ピンチを止められるかに挑戦。遊びながら、サッカーのオフサイドのルールが自然と身につきます。

■ パスの瞬間にラインを上げる
・あなたは赤チームの守備ライン。相手がドリブルやロングボールで攻めてくる
・ラインから遅れているDFの番号をタップすると、そのDFが自動で前に出てラインを上げる
・早すぎると相手FWに戻られる。パスの後では遅い。判定はボールを蹴った瞬間
・パスの瞬間はスローモーションになり、VARのように「後ろから2人目の守備者」と受け手の線、その差（cm）を表示
・受け手がボールに触れると、副審が旗を上げて「オフサイド！」

■ オフサイドにならない場面を見極める
・スローイン、ゴールキック、コーナーキックからはオフサイドにならない
・ボールより後ろの選手、自陣から走り出した選手もオフサイドにならない
・そんな場面ではラインを上げずに「マーク」ボタン。DFが体を寄せて競り勝つ
・ラインを上げてしまうとマークが外れて失点。どちらで守るかの判断がカギ

■ 実際のルール（サッカー競技規則 第11条）を再現
・キーパーも「後ろから2人目」に数える。キーパーが前に出ていたら、その後ろのDFを上げる
・オフサイドポジションにいても、プレーに関わらなければ反則ではない
・ロングボールでも判定はキックの瞬間。フリーキックやキーパーのスローはオフサイドがある
・ピッチの外に出たDFはゴールライン上にいるとみなす
・13種類の場面からランダムに出題。選手の配置も毎回変わる
・失点しても、なぜそうなったかを解説。タイトル画面の「オフサイドのルール」でいつでも確認できる

■ テレビ中継のような3D視点
・メインスタンドの上から守備ラインを横から見るので、ラインの高さがよくわかる
・満員のスタンド、太鼓と手拍子の応援、ゴール前でのどよめき
・オフサイドを取るたびに大歓声と花火

■ ナビで練習、ナビなしで本番
・ナビをオンにすると、今のオフサイドライン（赤い線）とパスの合図、判断のチェックリストが出る
・ナビなしで守ると得点1.5倍

■ その他
・「ザル守備」から「オフサイドトラップの支配者」までの称号
・スコアと称号を友だちにシェア（ナビあり／なしも表示）
・失点したプレーは、広告を見て同じ場面でやり直せる（1ゲーム5回まで）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、キックオフ。ラインをそろえて、相手を置き去りにせよ！
```
